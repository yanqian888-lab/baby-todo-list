### 1.2 过敏等级定义
- **低敏**：过敏风险低，排敏时间3天
- **中敏**：过敏风险中等，排敏时间3天
- **高敏**：过敏风险高，排敏时间5天

### 1.3 排敏完成规则
- **普通分类**（1-6）：该分类下完成3种食物的排敏，视为整个分类排敏完成，其他食物自动标记为已完成
- **中敏食材**（7）：该分类下完成5种食物的排敏，视为整个分类排敏完成
- **高敏食材**（8）：每个食物必须单独排敏，不受数量限制，建议1岁后添加

## 2. 排敏推荐算法

### 2.1 推荐原则
1. **优先级排序**：按照推荐优先级（10-100）从小到大顺序推荐
2. **分类优先**：优先推荐未完成分类中的食物
3. **排敏中的食物**：正在排敏中的食物高优推荐
4. **月龄限制**：仅推荐符合宝宝当前月龄的食物
5. **数量限制**：每次最多推荐3种食物
6. **分类完成判断**：自动判断分类是否完成

### 2.2 推荐流程

```
开始 → 获取用户排敏数据 → 计算各分类完成状态 → 筛选未排敏食物 → 按优先级排序 → 生成推荐列表 → 限制3种 → 输出推荐
```

### 2.3 算法详细步骤

#### 2.3.1 步骤1：获取用户数据
- 获取用户宝宝信息
- 获取已排敏食物记录
- 获取正在排敏中的食物
- 获取已完成分类信息

#### 2.3.2 步骤2：计算分类完成状态
```javascript
// 示例代码：计算分类完成状态
function calculateCategoryCompletion(categories, completedFoods) {
  const categoryStatus = {};
  
  categories.forEach(category => {
    const categoryFoods = completedFoods.filter(food => food.categoryId === category.id);
    let isCompleted = false;
    
    if (category.id >= 1 && category.id <= 6) {
      // 普通分类：完成3种视为分类完成
      isCompleted = categoryFoods.length >= 3;
    } else if (category.id === 7) {
      // 中敏食材：完成5种视为分类完成
      isCompleted = categoryFoods.length >= 5;
    } else if (category.id === 8) {
      // 高敏食材：不适用分类完成规则
      isCompleted = false;
    }
    
    categoryStatus[category.id] = { completed: isCompleted, count: categoryFoods.length };
  });
  
  return categoryStatus;
}
```

#### 2.3.3 步骤3：筛选未排敏食物
```javascript
// 示例代码：筛选未排敏食物
function filterUncompletedFoods(allFoods, completedFoods, categoryStatus, babyAgeMonths) {
  return allFoods.filter(food => {
    // 检查是否已排敏
    const isCompleted = completedFoods.some(completed => completed.id === food.id);
    if (isCompleted) return false;
    
    // 检查分类是否已完成
    if ((food.categoryId >= 1 && food.categoryId <= 7) && categoryStatus[food.categoryId]?.completed) {
      return false;
    }
    
    // 检查月龄限制
    const minAge = parseInt(food.minAge);
    if (babyAgeMonths < minAge) return false;
    
    return true;
  });
}
```

#### 2.3.4 步骤4：生成推荐列表
```javascript
// 示例代码：生成推荐列表
function generateRecommendations(uncompletedFoods, ongoingSensitivities) {
  // 优先推荐正在排敏中的食物
  const ongoing = ongoingSensitivities.map(rec => rec.foodId);
  const ongoingFoods = uncompletedFoods.filter(food => ongoing.includes(food.id));
  
  // 剩余食物按优先级排序
  const remainingFoods = uncompletedFoods.filter(food => !ongoing.includes(food.id));
  remainingFoods.sort((a, b) => a.priority - b.priority);
  
  // 合并并限制数量
  const recommendations = [...ongoingFoods, ...remainingFoods].slice(0, 3);
  
  return recommendations;
}
```

### 2.4 排敏天数计算规则

| 食物过敏等级 | 基础排敏天数 | 过敏反应 | 处理方式 |
|------------|-------------|---------|---------|
| 低敏/中敏 | 3天 | 不过敏 | 继续排敏，累计天数，完成后标注已完成 |
| 低敏/中敏 | 3天 | 轻微过敏 | 延长2天排敏天数，继续推荐；若连续3天轻微过敏，不再推荐 |
| 低敏/中敏 | 3天 | 重度过敏 | 立即停止，不再推荐 |
| 高敏 | 5天 | 不过敏 | 继续排敏，累计天数，完成后标注已完成 |
| 高敏 | 5天 | 轻微过敏 | 延长2天排敏天数，继续推荐；若连续3天轻微过敏，不再推荐 |
| 高敏 | 5天 | 重度过敏 | 立即停止，不再推荐 |

### 2.5 排敏进度计算

#### 2.5.1 进度计算公式
```
总食物数 = (普通分类数 × 3) + (中敏分类 × 5) + 高敏分类食物数
已完成食物数 = (已完成的普通分类数 × 3) + (已完成的中敏分类 × 5) + 已完成的高敏分类食物数
进度百分比 = (已完成食物数 / 总食物数) × 100
```

#### 2.5.2 示例
```
普通分类数：6 × 3 = 18
中敏分类：1 × 5 = 5
高敏分类食物数：13
总食物数：18 + 5 + 13 = 36

已完成普通分类数：2 × 3 = 6
已完成的中敏分类：0 × 5 = 0
已完成的高敏分类食物数：2
已完成食物数：6 + 0 + 2 = 8

进度百分比：(8 / 36) × 100 ≈ 22.2%
```

## 4. 算法边界条件

### 4.1 特殊情况处理
1. **新用户**：无任何排敏记录，按照优先级推荐前3种食物
2. **所有食物排敏完成**：显示"恭喜完成所有食物排敏"提示
3. **分类完成**：自动标记该分类下其他食物为已完成
4. **过敏反应**：根据反应等级调整排敏策略
5. **连续轻微过敏**：3天连续轻微过敏，停止该食物推荐

### 4.2 性能优化
1. **缓存机制**：缓存分类完成状态和推荐结果，减少重复计算
2. **数据预加载**：预加载用户排敏数据，提高响应速度
3. **批量处理**：批量更新排敏状态，减少数据库操作
4. **分页加载**：对于大量数据，采用分页加载策略
