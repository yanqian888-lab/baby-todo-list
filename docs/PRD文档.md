# 母婴打卡小程序 - PRD文档

## 1. 产品概述

### 1.1 产品定位
一款专为妈妈和婴幼儿家庭设计的日常事项打卡工具，帮助用户记录和管理育儿相关的各种事项，形成良好的生活习惯。

### 1.2 目标用户
- 妈妈群体
- 有婴幼儿的家庭
- 需要跟踪育儿日常的照顾者

### 1.3 核心价值
- 简单易用的育儿事项管理
- 养成规律的育儿习惯
- 记录婴幼儿成长的重要时刻
- 提供母婴相关事项建议

## 2. 功能需求

### 2.1 底部导航栏
- 包含两个Tab：打卡首页、我的
- 支持Tab间快速切换

### 2.2 打卡首页
- **待打卡区**
  - 按照需打卡日期由近及远展示事项
  - 循环事项仅展示循环期间内最近的一次
  - 点击事项卡片一键完成打卡
  - 支持左滑事项卡片，展示编辑和删除按钮
  - 删除事项时需二次确认
  
- **历史已完成事项**
  - 按照日期由远及近展示已完成的打卡事项
  
- **添加打卡事项按钮**
  - 点击跳转到事项建议页

### 2.3 事项建议页
- **建议事项**
  - 展示推荐的母婴相关事项
  - 点击后进入事项创建页，并带入预置参数
  
- **自定义事项**
  - 点击进入事项创建页，需手动添加所有参数

### 2.4 事项创建/编辑页
- **事项名称**
  - 从建议事项进入时不可更改
  - 自定义事项需手动填写，为必填项
  
- **副标题**
  - 非必填项，提供额外说明
  
- **循环设置**
  - 选项：不循环、每天、每周、每月
  - 必填项
  - 选择每周时，需选择具体周几
  - 选择每月时，需选择具体日期
  
- **次数设置**
  - 仅当循环选择"每天"时展示
  - 最多10次
  - 默认1次，必填项
  
- **完成按钮**
  - 保存事项设置并返回

### 2.5 我的页面
- **用户信息展示**
  - 显示用户头像
  - 显示用户昵称

## 3. 用户故事

### 3.1 核心用户故事
1. **记录日常喂养**
   - 作为妈妈，我希望能记录宝宝每天的喂养时间，以便掌握宝宝的饮食习惯
   
2. **管理疫苗接种**
   - 作为家长，我希望设置疫苗接种提醒，并在完成后打卡记录，以便不错过重要的接种时间
   
3. **培养规律作息**
   - 作为妈妈，我希望记录宝宝的睡眠情况，以帮助宝宝养成良好的作息习惯
   
4. **获取育儿建议**
   - 作为新手妈妈，我希望看到推荐的育儿事项，以便获取科学的育儿指导
   
5. **自定义特殊事项**
   - 作为家长，我希望能创建自定义事项，以便根据宝宝的具体情况进行个性化管理

## 4. 页面流程图

### 4.1 整体流程
```
启动小程序 -> 打卡首页 -> 待打卡事项/历史事项
                        |
                        v
             添加按钮 -> 事项建议页 -> 建议事项 -> 事项创建页
                                     |
                                     v
                                自定义事项 -> 事项创建页
                        
                        |
                        v
                    我的页面
```

### 4.2 打卡流程
```
打卡首页 -> 待打卡事项列表 -> 点击事项 -> 完成打卡 -> 事项移动到历史记录
```

### 4.3 事项管理流程
```
待打卡事项 -> 左滑 -> 编辑/删除
                 |
                 v
            编辑 -> 事项创建页 -> 保存修改
                 |
                 v
              删除 -> 二次确认弹窗 -> 确认删除/取消
```

### 4.4 事项创建流程
```
事项建议页 -> 建议事项/自定义事项 -> 事项创建页 -> 填写信息 -> 保存事项 -> 返回打卡首页
```

## 5. 详细页面设计

### 5.1 打卡首页
- **顶部导航栏**：标题"打卡首页"
- **待打卡区**：
  - 标题"待打卡"
  - 事项卡片列表，每张卡片包含：
    - 事项名称
    - 副标题（如有）
    - 打卡时间
    - 一键打卡按钮
- **历史记录区**：
  - 标题"历史记录"
  - 按日期分组的已完成事项列表
- **添加按钮**：浮动按钮，位于页面右下角

### 5.2 事项建议页
- **顶部导航栏**：标题"事项建议"，返回按钮
- **建议事项列表**：
  - 分类展示推荐事项
  - 每项包含名称和简要说明
- **自定义事项入口**：
  - 按钮或卡片形式
  - 明确的"自定义"标识

### 5.3 事项创建/编辑页
- **顶部导航栏**：标题"创建事项"/"编辑事项"，返回按钮
- **表单区域**：
  - 事项名称输入框
  - 副标题输入框
  - 循环设置选项组
  - 周几选择（当选择每周时显示）
  - 日期选择（当选择每月时显示）
  - 次数设置（当选择每天时显示）
- **底部操作栏**：
  - 完成按钮

### 5.4 我的页面
- **顶部导航栏**：标题"我的"
- **用户信息区域**：
  - 头像展示
  - 昵称显示

## 6. 数据需求

### 6.1 用户数据
- 用户基本信息（头像、昵称）
- 微信小程序用户ID

### 6.2 事项数据
- 事项ID
- 事项名称
- 副标题
- 循环类型（不循环/每天/每周/每月）
- 循环参数（周几/每月几号）
- 每日次数
- 创建时间
- 最后编辑时间

### 6.3 打卡记录数据
- 记录ID
- 事项ID
- 打卡用户ID
- 打卡时间
- 完成状态

## 7. 非功能需求

### 7.1 性能要求
- 页面加载时间不超过3秒
- 操作响应时间不超过1秒

### 7.2 用户体验要求
- 界面设计简洁可爱
- 操作流程简单直观
- 响应式布局适配不同尺寸设备

### 7.3 安全要求
- 用户数据加密存储
- 数据传输安全
- 隐私保护符合相关法规

## 8. 验收标准

### 8.1 功能验收
- 所有功能按照需求描述正常运行
- 打卡操作简单可靠
- 事项创建和编辑流程完整
- 左滑交互和删除确认功能正常

### 8.2 性能验收
- 页面加载和操作响应速度符合要求
- 在弱网环境下有良好的表现

### 8.3 兼容性验收
- 在不同尺寸的微信小程序环境中正常显示
- 兼容主流微信版本

## 9. 风险与依赖

### 9.1 潜在风险
- 循环事项的计算逻辑可能较为复杂
- 用户输入验证需要全面考虑

### 9.2 依赖项
- 微信小程序开发平台
- 微信云开发服务
- 数据库服务
