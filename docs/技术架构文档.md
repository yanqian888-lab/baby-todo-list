# 母婴打卡小程序 - 技术架构文档

## 1. 技术栈选择

### 1.1 前端技术
- **开发框架**：微信小程序原生开发框架
- **编程语言**：JavaScript
- **样式语言**：WXSS (微信小程序样式语言)
- **模板语言**：WXML (微信小程序模板语言)
- **组件化**：使用微信小程序自定义组件

### 1.2 后端技术
- **云开发平台**：微信云开发
- **数据库**：云数据库 (NoSQL)
- **云函数**：Node.js
- **云存储**：用于存储用户头像等媒体资源

### 1.3 开发工具
- **微信开发者工具**
- **版本控制**：Git

## 2. 系统架构设计

### 2.1 整体架构图
```
┌─────────────────────┐     ┌─────────────────────┐     ┌─────────────────────┐
│      前端应用       │     │      云开发         │     │      云数据库       │
│   (微信小程序)      │◄───►│      服务端         │◄───►│                     │
└─────────────────────┘     └─────────────────────┘     └─────────────────────┘
```

### 2.2 架构特点
- **前后端分离**：前端负责UI渲染和用户交互，后端负责数据处理和业务逻辑
- **无服务器架构**：使用微信云开发，无需搭建和维护服务器
- **云原生**：充分利用微信云开发的各项能力
- **实时数据同步**：支持数据的实时监听和更新

## 3. 开发方案

### 3.1 前端开发方案

#### 3.1.1 页面结构
- **首页 (index)**：打卡首页，展示待打卡和已完成事项
- **事项建议页 (task-recommend)**：展示推荐事项和自定义入口
- **事项创建页 (task-create)**：创建和编辑事项的表单页面
- **我的页面 (profile)**：用户信息展示页面

#### 3.1.2 组件规划
- **TaskCard**：事项卡片组件，支持一键打卡和左滑操作
- **ConfirmDialog**：确认对话框组件，用于删除确认等场景
- **WeekSelector**：周几选择组件，用于每周循环设置
- **DateSelector**：日期选择组件，用于每月循环设置
- **CountSelector**：次数选择组件，用于每天次数设置

#### 3.1.3 状态管理
- 使用微信小程序全局状态管理机制 (`globalData`)
- 页面间数据传递通过路由参数和事件总线实现

#### 3.1.4 网络请求
- 使用微信小程序的 `wx.cloud.callFunction` 调用云函数
- 使用微信小程序的 `wx.cloud.database` 直接操作云数据库

### 3.2 后端开发方案

#### 3.2.1 云函数设计
- 用户认证与信息管理
- 事项的增删改查操作
- 打卡记录的创建与查询
- 推荐事项的获取

#### 3.2.2 数据库设计
- 用户表 (users)
- 事项表 (tasks)
- 打卡记录表 (checkRecords)
- 推荐事项表 (recommendedTasks)

#### 3.2.3 安全与权限
- 使用微信云开发的安全规则进行数据库访问控制
- 实施基于用户身份的权限管理

## 5. 关键技术点

### 5.1 事项循环逻辑
- **每天循环**：生成当天的多个打卡时间点
- **每周循环**：根据选择的周几生成下次打卡时间
- **每月循环**：根据选择的日期生成下次打卡时间
- **循环终止条件**：支持按次数或日期限制循环

### 5.2 左滑交互实现
- 使用微信小程序的 `touch` 事件实现左滑手势识别
- 结合CSS transform实现平滑的滑动动画
- 管理滑动状态，确保用户体验的一致性

### 5.3 数据同步与离线支持
- 利用云数据库的实时监听功能实现数据同步
- 实现简单的缓存机制，支持部分离线操作
- 断网重连后自动同步本地数据

### 5.4 性能优化
- **列表渲染优化**：使用虚拟列表处理大量数据
- **图片优化**：使用云存储的图片压缩和裁剪能力
- **网络请求优化**：合并请求，减少不必要的网络交互
- **资源加载优化**：使用分包加载，优化小程序启动速度

## 6. 性能优化方案

### 6.1 前端性能优化
- **减少首屏加载时间**
  - 分包加载
  - 预加载关键资源
  - 减少不必要的组件渲染

- **提高页面响应速度**
  - 使用缓存减少重复计算
  - 优化数据查询条件
  - 组件化开发，提高复用性

### 6.2 后端性能优化
- **数据库索引优化**：为常用查询字段建立索引
- **云函数性能优化**：减少函数执行时间，避免阻塞
- **数据存储优化**：合理设计数据结构，减少冗余

## 10. 技术风险评估

### 10.1 已知风险
- 循环事项的时间计算可能存在边界情况
- 左滑交互在不同设备上的兼容性问题
- 大量数据下的性能表现可能不佳

### 10.2 风险缓解措施
- 编写详细的单元测试覆盖边界情况
- 在多种设备上进行兼容性测试
- 优化数据查询和渲染逻辑，分批加载大量数据
