# 宝宝辅食排敏小程序 - PRD文档

## 1. 产品概述

### 1.1 产品定位
一款专为5-6个月开始添加辅食的宝宝设计的食物排敏建议和记录工具，帮助家长科学地为宝宝引入新食物，降低过敏风险。

### 1.2 目标用户
- 宝宝5-6个月开始添加辅食的家长
- 需要科学指导进行食物排敏的妈妈群体
- 关注宝宝饮食健康的婴幼儿家庭

### 1.3 核心价值
- 科学的食物排敏顺序推荐
- 便捷的排敏记录和进度跟踪
- 个性化的排敏建议
- 完整的排敏历史记录

## 2. 功能需求

### 2.1 底部导航栏扩展
- 在原有导航栏基础上增加"排敏"Tab
- 排敏Tab作为独立项目运行，与打卡功能无交互

### 2.2 宝宝信息填写页（新用户首次进入排敏Tab）
- **基本信息**
  - 宝宝昵称（必填）
  - 出生日期（必填）
  - 性别选择（男/女，必填）
  - 已排敏食物勾选（非必填）

- **已排敏食物选择**
  - 按照分类展示所有排敏食物
  - 可多选已完成排敏的食物
  - 勾选默认已完成要求的排敏天数

### 2.3 排敏推荐流程
- **推荐算法**
  - 按照排敏顺序（0-100从小到大）推荐未排敏食物
  - 相同排序序号的食物可同时推荐
  - 小序号不足时由下一个序号补足
  - 每次最多推荐3种食物
  - 排敏中的食物高优推荐

- **分类排敏规则**
  - 普通分类（1-6）：排敏完成3种食物后，该分类下其他食物自动标注为已完成
  - 中敏食材（7）：需要完成5种食物的排敏
  - 高敏食材（8）：每个食物必须单独排敏

- **排敏天数要求**
  - 中敏/低敏食物：需连续排敏3天
  - 高敏食物：需连续排敏5天
  - 排敏完成后自动标注

### 2.4 每日排敏记录
- **排敏食物勾选**
  - 选择当天进行排敏的食物
  - 标注是否喜欢（喜欢、一般、不喜欢）
  - 标注是否过敏（不过敏、轻微过敏、重度过敏）

- **过敏处理逻辑**
  - 不过敏：进入3-5天排敏计数，继续高优推荐
  - 重度过敏：不再推荐该食物
  - 轻微过敏：自动延长2天排敏天数，继续高优推荐；若连续3天标注轻微过敏，则不再推荐

### 2.5 排敏进度展示
- 页面顶部显示整体排敏进度百分比
- 按照二级分类计算进度
- 实时更新进度数据

### 2.6 我的页面扩展
- **已排敏食物管理**
  - 增加已排敏食物的添加功能
  - 功能同新用户填写的"已排敏食物勾选"

- **排敏记录列表**
  - 按日期展示排敏记录
  - 显示每天排敏的食物和结果

## 3. 用户故事

### 3.1 核心用户故事
1. **首次使用排敏功能**
   - 作为新手妈妈，我希望能快速填写宝宝信息并开始科学的排敏流程

2. **获取排敏推荐**
   - 作为家长，我希望系统能按照科学顺序推荐适合宝宝当前阶段的排敏食物

3. **记录每日排敏情况**
   - 作为妈妈，我希望能方便地记录宝宝对食物的反应，包括是否喜欢和是否过敏

4. **查看排敏进度**
   - 作为家长，我希望能直观地看到宝宝的排敏进度，了解哪些食物可以安全食用

5. **管理已排敏食物**
   - 作为妈妈，我希望能手动添加宝宝已经排敏过的食物，以便系统更准确地推荐

## 4. 页面流程图

### 4.1 整体流程
```
启动小程序 -> 排敏Tab -> [新用户: 填写宝宝信息] -> 排敏推荐页 -> 每日排敏记录 -> 排敏进度更新
                                     |                             |
                                     v                             v
                              我的页面 -> 已排敏食物管理      我的页面 -> 排敏记录列表
```

### 4.2 排敏推荐流程
```
排敏推荐页 -> 展示推荐食物 -> 选择当天排敏食物 -> 填写排敏反馈 -> 保存记录 -> 更新排敏进度
```

### 4.3 已排敏食物管理流程
```
我的页面 -> 已排敏食物管理 -> 勾选已排敏食物 -> 保存 -> 更新排敏进度和推荐
```

## 5. 详细页面设计

### 5.1 宝宝信息填写页
- **顶部导航栏**：标题"宝宝信息"，返回按钮
- **基本信息表单**：
  - 昵称输入框（必填）
  - 出生日期选择器（必填）
  - 性别选择按钮组（男/女，必填）
- **已排敏食物选择**：
  - 按分类展示食物列表
  - 支持多选
  - 全选/取消全选功能
- **底部操作栏**：
  - 保存按钮

### 5.2 排敏推荐页
- **顶部进度条**：显示整体排敏进度百分比
- **推荐食物区域**：
  - 展示当天推荐的排敏食物（最多3种）
  - 每种食物显示名称、分类、排敏天数要求
  - 排敏中的食物标注"排敏中"状态
- **排敏记录表单**：
  - 选择当天进行排敏的食物
  - "是否喜欢"选择（喜欢/一般/不喜欢）
  - "是否过敏"选择（不过敏/轻微过敏/重度过敏）
- **底部操作栏**：
  - 提交记录按钮

### 5.3 我的页面扩展
- **排敏功能入口**：
  - 已排敏食物管理按钮
  - 排敏记录列表按钮

- **已排敏食物管理页**：
  - 按分类展示所有食物
  - 可勾选已排敏食物
  - 保存按钮

- **排敏记录列表页**：
  - 按日期倒序展示排敏记录
  - 每条记录显示日期、食物名称、反应结果
  - 支持查看详情

## 6. 数据需求

### 6.1 宝宝信息数据
- 宝宝ID
- 宝宝昵称
- 出生日期
- 性别
- 创建时间
- 更新时间

### 6.2 排敏食物分类数据
- 一级分类ID
- 一级分类名称
- 二级食物ID
- 二级食物名称
- 排敏顺序
- 过敏等级（低敏/中敏/高敏）
- 排敏天数要求

### 6.3 用户排敏记录数据
- 记录ID
- 用户ID
- 宝宝ID
- 食物ID
- 食物名称
- 日期
- 是否喜欢（0=不喜欢，1=一般，2=喜欢）
- 是否过敏（0=不过敏，1=轻微过敏，2=重度过敏）
- 排敏状态（0=未排敏，1=排敏中，2=已完成，3=过敏）
- 连续排敏天数
- 创建时间

### 6.4 排敏进度数据
- 进度ID
- 用户ID
- 宝宝ID
- 总排敏食物数
- 已完成排敏数
- 进度百分比
- 分类完成情况
- 更新时间

## 8. 排敏推荐算法逻辑

### 8.1 推荐顺序规则
1. 按照排敏顺序（0-100从小到大）推荐
2. 相同排序序号的食物可同时推荐
3. 小序号不足时由下一个序号补足
4. 每次最多推荐3种食物
5. 排敏中的食物高优推荐

### 8.2 分类完成规则
- 普通分类（1-6）：当该分类下已完成排敏3种食物时，该分类下其他食物自动标注为已完成
- 中敏食材（7）：需要完成5种食物的排敏
- 高敏食材（8）：每个食物必须单独排敏

### 8.3 排敏天数计算
- 低敏/中敏食物：连续排敏3天完成
- 高敏食物：连续排敏5天完成
- 排敏中的食物每天自动累计天数
- 达到要求天数后自动标注为已完成

### 8.4 过敏处理逻辑
- **不过敏**：继续累计排敏天数，完成后标注为已完成
- **轻微过敏**：自动延长2天排敏天数，继续高优推荐；若连续3天标注轻微过敏，则不再推荐
- **重度过敏**：立即停止该食物排敏，不再推荐
