# 宝宝辅食排敏小程序 - 开发规范与接口设计

## 1. 开发规范

### 1.1 命名规范

#### 1.1.1 文件命名
- **页面文件**：使用小写字母和连字符，前缀`sensitivity-`
  - 示例：`sensitivity/index.js`
- **组件文件**：使用大写字母开头的驼峰命名法，前缀`Sensitivity`
  - 示例：`SensitivityFoodItem.js`
- **工具文件**：使用小写字母和下划线，前缀`sensitivity_`
  - 示例：`sensitivity_utils.js`
- **样式文件**：与页面文件同名，使用`.wxss`扩展名
  - 示例：`sensitivity/index.wxss`

#### 1.1.2 函数命名
- **云函数**：使用小写字母和连字符，前缀`sensitivity-`
  - 示例：`sensitivity-get-recommendations`
- **前端函数**：使用驼峰命名法，前缀`sensitivity`
  - 示例：`sensitivityGetRecommendations()`

#### 1.1.3 数据库命名
- **集合名称**：使用小写字母和下划线，前缀`sensitivity_`
  - 示例：`sensitivity_foods`
- **字段名称**：使用小写字母和下划线
  - 示例：`user_id`, `baby_info`

#### 1.1.4 变量命名
- **全局变量**：使用大写字母和下划线，前缀`SENSITIVITY_`
  - 示例：`SENSITIVITY_MAX_RECOMMENDATIONS`
- **局部变量**：使用驼峰命名法
  - 示例：`currentFoodList`

### 1.3 代码规范

#### 1.3.1 JavaScript代码规范
- 使用ES6+语法
- 缩进使用2个空格
- 变量声明使用`const`或`let`，避免使用`var`
- 函数定义优先使用箭头函数
- 字符串使用单引号
- 对象字面量使用简洁表示法
- 数组和对象初始化时避免多余的逗号

```javascript
// 示例：符合规范的代码
const sensitivityGetRecommendations = async (userId, babyId) => {
  try {
    const result = await wx.cloud.callFunction({
      name: 'sensitivity-get-recommendations',
      data: { userId, babyId }
    });
    return result.result;
  } catch (error) {
    console.error('获取推荐食物失败:', error);
    throw error;
  }
};
```

#### 1.3.2 WXML代码规范
- 缩进使用2个空格
- 标签名称使用小写字母
- 属性值使用双引号
- 避免使用内联样式
- 使用数据绑定代替硬编码

```html
<!-- 示例：符合规范的WXML代码 -->
<view class="sensitivity-recommendation">
  <sensitivity-food-item
    wx:for="{{recommendations}}"
    wx:key="id"
    food="{{item}}"
    onTap="{{handleFoodTap}}"
  />
</view>
```

#### 1.3.3 WXSS代码规范
- 使用BEM命名规范
- 避免使用ID选择器
- 使用相对单位（rpx）
- 颜色值使用十六进制表示
- 样式模块化，避免全局污染

```css
/* 示例：符合规范的WXSS代码 */
.sensitivity-recommendation {
  padding: 20rpx;
  background-color: #ffffff;
}

.sensitivity-recommendation__food-item {
  margin-bottom: 16rpx;
  border-radius: 8rpx;
  box-shadow: 0 2rpx 8rpx rgba(0, 0, 0, 0.1);
}
```

## 4. 前端API接口设计

### 4.1 通用请求封装

```javascript
// services/sensitivity/sensitivity_api.js

// 封装云函数调用
export const sensitivityCallFunction = async (name, data) => {
  try {
    const result = await wx.cloud.callFunction({
      name,
      data
    });
    
    if (result.result.success) {
      return result.result.data;
    } else {
      throw new Error(result.result.error || '调用失败');
    }
  } catch (error) {
    console.error(`调用云函数${name}失败:`, error);
    wx.showToast({
      title: '操作失败',
      icon: 'none'
    });
    throw error;
  }
};
```

## 6. 错误处理规范

### 6.1 错误类型

| 错误类型 | 错误代码 | 描述 |
|---------|---------|------|
| 参数错误 | 400 | 请求参数错误 |
| 认证错误 | 401 | 用户未登录 |
| 权限错误 | 403 | 用户无权限 |
| 资源不存在 | 404 | 请求的资源不存在 |
| 服务器错误 | 500 | 服务器内部错误 |
| 业务错误 | 600 | 业务逻辑错误 |

### 6.2 错误处理流程

1. **前端错误处理**：
   - 捕获API调用错误
   - 显示友好的错误提示
   - 记录错误日志

```javascript
try {
  const result = await sensitivityGetRecommendations(babyId);
  // 处理成功结果
} catch (error) {
  console.error('获取推荐失败:', error);
  wx.showToast({
    title: '获取推荐失败，请重试',
    icon: 'none'
  });
}
```

2. **后端错误处理**：
   - 捕获业务逻辑错误
   - 返回标准化的错误响应
   - 记录详细错误日志

```javascript
try {
  // 业务逻辑
  return {
    success: true,
    data: result
  };
} catch (error) {
  console.error('业务错误:', error);
  return {
    success: false,
    error: error.message || '服务器内部错误',
    code: 500
  };
}
```
