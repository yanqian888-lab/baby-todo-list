# 母婴打卡小程序 - UI设计规范文档

## 1. 设计理念与风格

### 1.1 设计理念

我们的UI设计理念围绕着「温暖」、「简洁」和「易用」三个核心原则展开，旨在为年轻妈妈们提供一个视觉友好、操作简单的育儿助手。

- **温暖**: 通过暖色系色彩搭配，营造温馨舒适的氛围，让用户在使用过程中感受到关爱的温度
- **简洁**: 简约扁平的设计风格，避免视觉干扰，让核心功能一目了然
- **易用**: 直观的操作流程和清晰的视觉反馈，降低学习成本，提升用户体验

### 1.2 风格特征

- **可爱简约**: 圆润的边角、简洁的图形元素、柔和的阴影效果
- **扁平设计**: 避免复杂的渐变和纹理，使用纯色块和简单的几何形状
- **暖色系**: 以暖色调为主，营造温馨、亲切的氛围
- **易读性**: 清晰的字体层次和足够的留白，确保信息易于阅读

## 3. 排版规范

### 3.1 字体

- **主要字体**: 微信系统默认字体 (iOS: PingFang SC, Android:思源黑体)
- **备用字体**: "Helvetica Neue", Helvetica, Arial, sans-serif

### 3.2 字体大小

| 字体级别 | 字体大小 | 行高 | 用途 | 颜色 |
|---------|---------|------|------|------|
| 大标题 | 18px | 24px | 页面标题、重要内容 | #333333 |
| 中标题 | 16px | 22px | 卡片标题、section标题 | #333333 |
| 小标题 | 14px | 20px | 列表标题、次要标题 | #333333 |
| 正文 | 14px | 20px | 主要文本内容 | #333333 |
| 次要文本 | 12px | 18px | 辅助说明、提示文本 | #999999 |
| 小文本 | 11px | 16px | 标签、状态文本 | #999999 |

### 3.3 文本样式

- **标题**: 字重600 (半粗体)
- **正文**: 字重400 (常规)
- **强调文本**: 主色调或字重600
- **链接文本**: 主色调，无下划线

## 4. 图标规范

### 4.1 图标风格

- **风格**: 线性 + 填充，扁平化设计
- **圆角**: 保持一致的圆角半径
- **线条**: 保持2px的线条粗细
- **尺寸**: 根据不同场景提供多种尺寸

### 4.2 图标尺寸

| 尺寸 | 用途 |

| 48px | 主要功能图标、引导图标 |

- **主要图标**: 使用自定义设计的母婴主题图标

## 6. 布局规范

### 6.1 页面结构

- **顶部导航栏**: 高度88px，固定定位
- **内容区域**: 自适应高度，底部安全区域16px
- **底部Tab栏**: 高度92px，固定定位，包含安全区域

### 6.2 间距规范

| 间距级别 | 像素值 | 用途 |
|---------|-------|------|
| xs | 4px | 组件内部元素间距 |
| sm | 8px | 小型组件间距 |
| md | 12px | 标准组件间距 |
| lg | 16px | 主要内容区域间距 |
| xl | 24px | 页面区块间距 |
| xxl | 32px | 大空间分隔 |

### 6.3 响应式设计

- **设计稿尺寸**: 375px (iPhone X/11/12 mini)
- **适配策略**: 
  - 宽度: 使用rpx单位自动适配
  - 高度: 固定值 + rpx结合使用
  - 字体: 使用rpx单位
  - 图片: 适当使用flex布局和宽高比

## 8. 交互规范

### 8.1 点击反馈

- **按钮点击**: 50%透明度反馈，持续时间150ms
- **卡片点击**: 轻微阴影变化和位移反馈
- **列表项点击**: 背景色变化，持续时间200ms

### 8.2 过渡动画

- **页面切换**: 左右滑动过渡，持续时间300ms
- **弹窗动画**: 从底部向上滑入，持续时间250ms
- **加载动画**: 骨架屏过渡或淡入效果

### 8.3 手势操作

- **左滑**: 列表项左滑显示操作按钮
- **下拉刷新**: 页面内容下拉刷新
- **点击长按**: 显示额外操作菜单

## 9. 其他规范

### 9.1 图标使用规范

- 图标应保持一致性，风格统一
- 每个功能区域使用对应语义化的图标
- 确保图标的可识别性，避免过于复杂的设计

### 9.2 提示信息规范

- **成功提示**: 绿色背景，白色文字，3秒后自动消失
- **错误提示**: 红色背景，白色文字，3秒后自动消失
- **加载提示**: 主色调加载动画，可包含文字提示

### 9.3 适配与安全区域

- **iPhone X及以上机型**: 顶部导航栏需考虑刘海屏安全距离
- **底部导航**: 需考虑底部安全区域，增加内边距
- **横屏适配**: 保持关键内容在可视区域内

## 10. 设计资源

### 10.1 设计文件

- 设计源文件使用Sketch或Figma制作
- 组件库文件单独维护，确保复用性
- 图标资源提供SVG和PNG两种格式

### 10.2 命名规范

- **文件命名**: 页面_组件_状态
- **图层命名**: 功能_类型_序号
- **资源命名**: 图标名称_尺寸
