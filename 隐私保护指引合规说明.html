3 提交操作步骤
  1. 登录 mp.weixin.qq.com 微信公众平台
  2. 进入 设置 → 服务内容声明 → 用户隐私保护指引
  3. 点击「更新」或「配置」，在信息类型列表中勾选以下3项：
    ☑ 微信昵称（选择后填写用途和接口）
    ☑ 微信头像（选择后填写用途和接口）
    ☑ 微信开放账号（OpenID）（选择后填写用途和接口）
  4. 每项填写对应的「业务功能」和「调用接口」信息（参考第2节的表格内容）
  5. 确认「是否涉及第三方」均选择 「否」
  6. 填写隐私政策链接：指向小程序内的隐私政策页面（/pages/privacy-policy/index）
  7. 提交审核，等待微信平台审核通过（通常1-3个工作日）
注意：用户隐私保护指引审核通过后，小程序才能正常使用 chooseAvatar 和 type="nickname" 等接口。未提交或审核未通过时，这些接口将无法调用。
4 代码配置说明

app.json 已配置项

{ // 启用隐私合规检查（用户调用隐私接口时弹出授权弹窗） "__usePrivacyCheck__": true, // 启用隐私保护配置 "privacy": { "enable": true } }

授权页面（auth.js）实现方式

// 头像选择：使用 chooseAvatar 能力，非已废弃的 getUserProfile <button open-type="chooseAvatar" bind:chooseavatar="onChooseAvatar"> <image src="{{avatarUrl || '/images/touxiang_moren.png'}}" /> </button> // 昵称输入：使用 type="nickname" 能力，非直接获取微信昵称 <input type="nickname" placeholder="点击输入昵称（选填）" /> // 处理逻辑：未填昵称 → 云函数生成随机昵称兜底 // 未选头像 → 使用默认头像兜底 const userInfo = { nickName: that.data.nickName || undefined, avatarUrl: that.data.avatarUrl || '/images/touxiang_moren.png', };
合规要点：本小程序使用的是微信推荐的 「头像昵称填写能力」（chooseAvatar + type="nickname"），而非已废弃的 wx.getUserProfile 或 wx.getUserInfo。这种方式下，用户自主选择是否提供头像和昵称，更符合隐私保护要求。

// 建议修改后的表述： 您通过微信账号登录本小程序时，我们将通过微信提供的 「头像昵称填写能力」（chooseAvatar）引导您自主选择 是否提供微信头像和昵称，该信息仅用于小程序内用户身份 标识、个人主页展示及家庭成员列表显示，帮助您快速完 成登录。您可自主选择是否提供，未提供时系统将自动生 成默认头像和昵称。我们不会通过 wx.getUserProfile 等已废弃接口直接获取您的微信资料，也不会收集您的微 信账号密码、手机号、好友列表等未授权信息。
